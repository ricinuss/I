Nota sobre o funcionamento: Não há geração de resposta automática via IA integrada para nenhum desses códigos. Como o serviço deste site é totalmente gratuito, não irei arcar com os custos de tokens de APIs externas utilizados por terceiros. Use as funções para copiar as informações e envie para a IA de sua preferência por conta própria.

Scripts Disponíveis

ricinusWriter

Escreve automaticamente as suas redações para a plataforma Redação Paraná.

ricinusSkip

Pula automaticamente os vídeos do Inglês Paraná.

ricinusReader Em breve

Passa páginas do livro automaticamente e copia a resposta para já enviar para uma IA.

funnywave

Modificações visuais e customizações de interface.

flappiden

Mini-game e utilitários alternativos executados no navegador.

Como executar os scripts:

  1. Clique no botão copiar do script desejado.
  2. Abra o console do seu navegador:
    • No Chrome/Edge/Brave: Ctrl + Shift + J
    • No Firefox: Ctrl + Shift + K
  3. Se for sua primeira vez, o navegador pode bloquear a colagem. Se aparecer um aviso, digite exatamente:
    allow pasting e aperte Enter.
  4. Agora, cole o código (Ctrl + V) e aperte Enter para rodar.
